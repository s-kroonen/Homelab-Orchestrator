Connections

The systems the orchestrator talks to. Changes apply at once, no restart.

How this works

Connections are kept in connections.yaml and apply the moment you save. Secrets are never shown again once saved; leave a secret blank to keep what is stored. Test only reads: it never changes anything on the other side.

A kind that allows several (Portainer) has a default one; a service's controller uses the default unless it names another.

Who uses which

each service's controller acts through a connection

Share with another orchestrator

Connections marked shared are the ones a second orchestrator (another site) should have too. An export leaves secrets out unless you ask; an import arrives switched off.
