Waking before a backup

Services that must be up for this policy's backups. They are woken first (before PBS is even checked) and held awake until the backup finishes, so the power manager's idle shutdown cannot pull them mid-dump. Typical choice: the storage VM (e.g. TrueNAS) hosting the NFS the PBS datastore lives on. Each is woken through its own node only — what it needs is not followed. This is not depends_on (a health-gate dependency that never wakes anything).
