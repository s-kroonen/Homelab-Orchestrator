Data sources

Nodes and guests belong to Proxmox, routes to Traefik Manager, stacks to Portainer, addresses to the guests themselves. They are not created or edited by hand here: you pull them (refresh, import what is new) and, for routes, format them into one standard shape. What only this orchestrator knows (probes, policies, power targets) stays on its own pages.

Fills blank node addresses, checks every node, re-reads every guest and scans the services on them. Addresses set by hand are never overwritten.
