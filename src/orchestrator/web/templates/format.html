Format routes

Rewrites hand-written and migrated routes into what Traefik Manager creates for a new host and what this orchestrator creates by default: a router named orchestrator-<host> in the configured config file, the Host header passed through, a companion HTTP → HTTPS redirect router (the old way's redirect middleware is dropped), and the certificate resolver. One host at a time: the new route is created beside the old one, Traefik has to load it, then the old one is removed and read back. If a step fails the new route is removed and the old one is restored; a snapshot of each old route is saved first. Routes it cannot rewrite without losing something (path rules, several servers, shared services…) are left alone. Hosts that are switched off are not touched.
