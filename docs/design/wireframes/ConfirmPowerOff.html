Power off node-a?

node-a is marked always on. Powering it off also stops:

  • 14 services, including haos, nextcloud, mailcow and portainer
  • gateway-vm: every proxy host stops answering
  • The Proxmox API the orchestrator uses to wake other nodes
  • Tonight’s backups, until it is back
